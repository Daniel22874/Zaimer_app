## **Инструкция по использованию приложения**

Приложение создано для ведения клиентов и учёта их займов. Нииже приведены описания окон приложения, 
из которых оно состоит. 
---
## Основное окно
[Картинка основного окна](screenshots/main_window.png)

При открытии приложения открывается основное окно. На нем отображается таблица всех клиентов, 
которые брали займ. Также есть кнопка добавления нового клиента и кнопка для просмотра займов текущего клиента 
(будет работать, если в таблице выбрана строка с клиентом).

---
## Окно добавления клиента
[Картинка окна добавления займов](screenshots/add_client_window.png)

На окне отображены поля для ввода ФИО, телефона и паспорта. Кнопка ОК добавляет всю инфу о клиенте в БД.

---
## Окно для просмотра займов
[Картинка окна для просмотра займов](screenshots/loans_window.png)

На окне отображается таблица всех займов выбранного клиента. Ниже расположены кнопки добавления нового займа, 
внесения платежа активного займа (нужно выбрать строку с активным займом, на погашенных займах работать не будет), 
просмотра истории платежей выбранного клиента.

---
## Окно создания нового займа
[Картинка окна создания нового займа](screenshots/new_loan_window.png)

На окне отображены поля для ввода суммы оформляемого займа, срока займа в месяцах и процентной ставки, под которую 
он берётся. Кнопка "Выдать займ" добавляет созданный займ в БД.

---
## Окно внесения платежа
[Картинка окна внесения платежа](screenshots/new_payment_window.png)

На окне отображены поля для ввода суммы платежа и комментария. Кнопка "Оплатить" добавляет внесённый платёж в БД 
(если сумма платежа больше или равна сумме займа, иначе выводится соответствующее оповещение).

---
## Окно для просмотра истории платежей
[Картинка окна для просмотра истории платежей](screenshots/history_payment_window.png)

На окне отображается таблица всех платежей по займам выбранного клиента.
